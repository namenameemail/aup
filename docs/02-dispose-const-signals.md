# Один const на параметр, менять значение

`Parameter.frequency` и `Parameter.amplitude` при каждом const-значении делают `new ConstModule(value)`. Внутри это `Tone.Signal`: он сразу запускает `ConstantSource`, а при `connect` обнуляет `AudioParam`. Дальше числом параметра является этот сигнал, не собственное значение `AudioParam`.

Новый `ConstModule` на каждое изменение оставляет старый `ConstantSource` работать. `dispose` старого сигнала тоже не подходит: на время между отключением и новым `connect` параметром никто не управляет, и он остаётся нулём.

Чужой ADSR или LFO по-прежнему не уничтожать. Он принадлежит голосу-источнику.

## Сделать

- Завести по одному `ConstModule` на frequency и на amplitude и подключать его при первом const.
- Следующие const писать в уже существующий сигнал (`value` / `setValueAtTime`), не создавая новый и не отключая его.
- При патче от ADSR или LFO const только отключить и оставить жить. При возврате к const подключить тот же модуль и записать новое значение.
