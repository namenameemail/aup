# Запускать AudioContext из жеста

`SynthBody` вызывает `Tone.start()` в конструкторе. Конструктор выполняется в `useEffect` после первого рендера, это не пользовательский жест. Браузер отклоняет `resume`, в консоли остаётся `AudioContext was not allowed to start`. Повторного вызова на attack нет, контекст так и остаётся suspended, огибающая планируется в остановленном времени.

## Сделать

- Убрать `Tone.start()` из конструктора `SynthBody`.
- Вызывать `Tone.start()` синхронно внутри обработчика жеста, до `triggerAttack` / `triggerRelease`. Жесты: кнопка attack и клавиатурный `keydown`.
- Не делать `await Tone.start()`. После `await` вызов уже вне стека события, и браузер снова может отказать.
